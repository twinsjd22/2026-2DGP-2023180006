# 소년 상하좌우 이동 PRD

> 원본 기획: [PRE_PRD.md](PRE_PRD.md)
> 브랜치: `feature/lec10-assignment`

## 1. 개요

방향키(↑ ↓ ← →)로 소년 캐릭터를 상하좌우로 움직이는 프로그램을 만든다.
LEC10 실습 `move_character_with_key.py`(좌우 이동)와 `move_character_with_mouse.py`(TUK_GROUND 배경)를 바탕으로, 세로 이동과 바라보는 방향, 대기 애니메이션, 화면 경계 처리를 더한다.

## 2. 목표

- 방향키 네 개로 소년을 **상하좌우**로 이동한다.
- 좌우로 이동하면 **그 방향으로 달리는 애니메이션**이 나오고, 소년이 그 방향을 바라본다.
- 위아래로 이동할 때는 **바라보던 방향을 그대로 유지**한 채 달리는 애니메이션이 나온다.
- 아무 키도 누르지 않으면 바라보던 방향의 **대기(IDLE) 애니메이션**이 나온다.
- 화면 경계에 닿으면 그 방향으로는 **더 이상 이동하지 않는다**.

### 범위 밖

- 마우스 입력, 점프·공격 같은 다른 동작
- 위/아래를 바라보는 전용 스프라이트 (시트에 없음)
- 대각선 이동 속도 보정 (두 키를 같이 누르면 그대로 대각선으로 이동한다)
- 클래스 설계, 여러 파일로 나누기

## 4. 리소스 분석

### `animation_sheet.png`

- 크기: **802 × 402 px**, RGBA, 배경 투명
- 한 칸이 **100 × 100**인 격자로, **4줄 × 8프레임**이다.
- pico2d의 `clip_draw`는 **왼쪽 아래가 원점**이므로 줄 위치(bottom)는 아래 표와 같다.

| bottom | 이미지에서의 줄(위부터) | 동작                |
| ------ | ----------------------- | ------------------- |
| 300    | 1번째                   | 대기, 오른쪽 바라봄 |
| 200    | 2번째                   | 대기, 왼쪽 바라봄   |
| 100    | 3번째                   | 달리기, 오른쪽      |
| 0      | 4번째                   | 달리기, 왼쪽        |

프레임 하나는 `clip_draw(frame * 100, bottom, 100, 100, x, y)`로 그린다.

### `TUK_GROUND.png`

- 크기: **1280 × 1024 px**. 화면 가운데 `(640, 512)`에 원본 크기로 그리면 화면을 꽉 채운다.

## 5. 기능 요구사항

| ID | 요구사항                                                                                                                 |
| -- | ------------------------------------------------------------------------------------------------------------------------ |
| F1 | 실행하면 1280 × 1024 캔버스를 열고`TUK_GROUND.png`를 배경으로 그린다.                                                 |
| F2 | 소년은 화면 가운데에서**오른쪽을 바라보는 대기 상태**로 시작한다.                                                  |
| F3 | ← → 키로 가로 방향`dir_x`를, ↑ ↓ 키로 세로 방향 `dir_y`를 바꾼다. 누르면 더하고 떼면 되돌린다(실습과 같은 방식). |
| F4 | 매 프레임`x += dir_x * MOVE_SPEED`, `y += dir_y * MOVE_SPEED`로 위치를 옮긴다.                                       |
| F5 | `dir_x`가 양수면 오른쪽, 음수면 왼쪽을 바라본다(`face_dir`). `dir_x`가 0이면 **이전 방향을 유지**한다.       |
| F6 | `dir_x` 또는 `dir_y`가 0이 아니면 `face_dir` 방향의 **달리기** 줄을, 둘 다 0이면 **대기** 줄을 그린다. |
| F7 | 소년의 x, y는 화면 안에 머문다. 경계에 닿으면 그 방향으로 더 움직이지 않는다(`clamp`).                                 |
| F8 | 창을 닫거나 ESC를 누르면 종료한다.                                                                                       |

### 상태 정리

| 누르고 있는 키 | dir_x | dir_y | face_dir     | 그리는 줄(bottom)    |
| -------------- | ----- | ----- | ------------ | -------------------- |
| 없음           | 0     | 0     | 이전 값 유지 | 대기 (300 또는 200)  |
| →             | 1     | 0     | 1 (오른쪽)   | 달리기 오른쪽 (100)  |
| ←             | -1    | 0     | -1 (왼쪽)    | 달리기 왼쪽 (0)      |
| ↑ 또는 ↓     | 0     | ±1   | 이전 값 유지 | face_dir 방향 달리기 |
| → + ↑        | 1     | 1     | 1            | 달리기 오른쪽 (100)  |

## 6. 비기능 요구사항

- **설정값은 상수로**: `TUK_WIDTH = 1280`, `TUK_HEIGHT = 1024`, `FRAME_SIZE = 100`, `MOVE_SPEED`, `FRAME_DELAY`를 파일 위쪽에 모은다.
- **줄 번호도 상수로**: `IDLE_RIGHT = 300`, `IDLE_LEFT = 200`, `RUN_RIGHT = 100`, `RUN_LEFT = 0`. 숫자를 코드 곳곳에 직접 쓰지 않는다.
- **경계값 계산**: 소년 그림의 가운데가 (x, y)이므로 이동 범위는 `FRAME_SIZE // 2` ~ `화면 크기 - FRAME_SIZE // 2`로 둔다.
- **역할 나누기**: 입력은 `handle_events()`, 위치·방향 갱신은 `update_boy()`, 그리기는 `draw_boy()`가 맡는다.

## 8. 코드 구조

```python
from pico2d import *

# 1. 설정 상수
TUK_WIDTH, TUK_HEIGHT = 1280, 1024
FRAME_SIZE, MOVE_SPEED, FRAME_DELAY
IDLE_RIGHT, IDLE_LEFT, RUN_RIGHT, RUN_LEFT = 300, 200, 100, 0

# 2. 캔버스, 이미지 로드
open_canvas(TUK_WIDTH, TUK_HEIGHT)
tuk_ground = load_image('TUK_GROUND.png')
character = load_image('animation_sheet.png')

# 3. 함수
def handle_events(): ...   # 방향키 → dir_x, dir_y / 종료
def update_boy(): ...      # 위치 이동, face_dir 갱신, 경계 제한
def draw_boy(): ...        # 상태에 맞는 줄을 골라 clip_draw

# 4. 상태 변수
running = True
x, y = TUK_WIDTH // 2, TUK_HEIGHT // 2
dir_x, dir_y = 0, 0
face_dir = 1
frame = 0

# 5. 메인 루프
while running:
    clear_canvas()
    tuk_ground.draw(TUK_WIDTH // 2, TUK_HEIGHT // 2)
    draw_boy()
    update_canvas()
    handle_events()
    update_boy()
    frame = (frame + 1) % 8
    delay(FRAME_DELAY)

close_canvas()
```
