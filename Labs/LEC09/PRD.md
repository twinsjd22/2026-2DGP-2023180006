# Sonic 애니메이션 뷰어 PRD

> 원본 기획: [PRE_PRD.md](PRE_PRD.md)
> 브랜치: `feature/lec09-animation-viewer`

## 1. 개요

`sonic-sprite.png` 스프라이트시트에 들어 있는 소닉의 모든 동작 애니메이션을 차례대로 화면에 재생하는 뷰어를 만든다.
LEC08의 `animation_viewer.py`(커비 뷰어)와 같은 방식(pico2d, `clip_draw`, 프레임 좌표 리스트)을 따른다.

## 2. 목표

- 스프라이트시트의 모든 동작을 빠짐없이 재생한다.
- 동작마다 **5초 재생 → 1초 정지 → 다음 동작** 순서로 진행한다.
- 마지막 동작이 끝나면 처음부터 **무한 반복**한다.
- 캐릭터가 화면에서 잘 보이도록 **확대**해서 그린다.
- 걷기·달리기처럼 **이동이 포함된 동작은 실제로 화면에서 가로로 이동**하면서 재생한다. (제자리 재생만으로는 이동 동작을 확인하기 어렵기 때문)

### 범위 밖

- 키보드/마우스 입력, 동작 선택 UI
- 배경, 사운드
- 세로 이동(점프 높이 등), 가속·감속 같은 물리 표현
- 여러 파일로 나누기, 클래스 설계

## 4. 리소스 분석: `sonic-sprite.png`

- 크기: **399 × 525 px**, RGBA, 배경 투명
- 프레임 크기가 동작마다 달라서 **프레임마다 (left, bottom, width, height)를 직접 측정**해야 한다.
- pico2d의 `clip_draw`는 **왼쪽 아래가 원점**이다. 이미지 편집기(왼쪽 위 원점)에서 잰 y 좌표는 `bottom = 525 - (위에서 잰 아래쪽 y) - 1`로 바꾼다.

이미지에서 스프라이트가 있는 가로 줄(위에서부터 잰 y 범위)은 다음과 같다. 동작 이름은 그림을 보고 붙인 임시 이름이라 구현하면서 고쳐도 된다.

| 줄 | y 범위(위 기준) | 내용(추정)                   | 대략 프레임 수 |
| -- | --------------- | ---------------------------- | -------------- |
| -  | 1 ~ 32          | 제목 "Classic Sonic Sprites" | 제외           |
| 1  | 39 ~ 77         | 대기 / 기다리기              | 약 11          |
| 2  | 79 ~ 117        | 걷기 → 달리기               | 약 12          |
| 3  | 121 ~ 163       | 전력 질주                    | 약 6           |
| 4  | 167 ~ 199       | 스핀(구르기 시작)            | 약 9           |
| 5  | 206 ~ 232       | 볼(스핀 대시)                | 약 6           |
| 6  | 238 ~ 273       | 점프 / 회전                  | 약 6           |
| 7  | 283 ~ 317       | 피겨에이트 달리기            | 약 6           |
| 8  | 326 ~ 370       | 위 보기·숙이기·밀기 등     | 약 9           |
| 9  | 377 ~ 416       | 균형 잡기 / 기타             | 약 8           |
| 10 | 426 ~ 468       | 피격 / 기타                  | 약 4           |
| -  | 472 ~ 524       | 크레딧 문구, 다른 캐릭터     | 제외           |

한 줄에 동작이 두 개 이상 섞여 있으면 동작 단위로 리스트를 나눈다.

## 5. 기능 요구사항

| ID | 요구사항                                                                                       |
| -- | ---------------------------------------------------------------------------------------------- |
| F1 | 실행하면 **1200 × 800** 캔버스를 열고 `sonic-sprite.png`를 불러온다.                                         |
| F2 | 동작마다 프레임 좌표 리스트를 둔다. (`idle_frames`, `walk_frames` …)                      |
| F3 | 프레임 리스트를 받아서 재생하는 함수 `play_animation(frames)`를 둔다.                         |
| F4 | 한 동작은 **5초 동안** 프레임을 반복 재생한다. 프레임 수와 상관없이 시간 기준으로 끊는다. |
| F5 | 동작 하나가 끝나면 **1초 동안** 마지막 화면을 유지한다(정지).                             |
| F6 | 모든 동작을 정해진 순서로 재생하고, 끝나면 처음부터 다시 재생한다(무한 반복).                  |
| F7 | 스프라이트를 **배율(SCALE)** 만큼 확대해서 그린다.                                        |
| F8 | 프레임 높이가 달라도 발 위치가 흔들리지 않도록 **바닥선(GROUND_Y)에 맞춰** 그린다.        |
| F9 | 창을 닫거나 ESC를 누르면 프로그램이 종료된다. (`get_events()`로 처리)                        |
| F10 | 동작마다 **가로 이동 속도(px/초)**를 둔다. 제자리 동작은 0, 오른쪽 이동은 양수, 왼쪽 이동은 음수. (표는 10장) |
| F11 | 이동 동작은 **경과 시간 × 속도**만큼 x 위치를 옮긴다. 프레임 간격과 상관없이 같은 속도로 움직인다. |
| F12 | 화면 밖으로 나가면 **반대쪽 가장자리에서 다시 들어온다**(화면 감싸기). |
| F13 | 제자리 동작은 화면 가운데(`CENTER_X`)에서, 오른쪽 이동은 왼쪽 가장자리에서, 왼쪽 이동은 오른쪽 가장자리에서 출발한다. |
| F14 | 1초 정지 동안에는 마지막 프레임을 **마지막 위치에 그대로** 둔다. |

## 6. 비기능 요구사항

- **설정값은 상수로**: `SCREEN_WIDTH = 1200`, `SCREEN_HEIGHT = 800`, `SCALE`, `CENTER_X = SCREEN_WIDTH // 2`, `GROUND_Y`, `FRAME_DELAY`, `PLAY_TIME = 5`, `PAUSE_TIME = 1`, 이동 속도(`WALK_SPEED` 등), `START_OFFSET`, `EDGE_MARGIN`을 파일 위쪽에 모은다.
- **화면 안에 들어오게**: 가장 큰 프레임에 배율을 곱해도 캔버스(1200 × 800)를 넘지 않게 배율을 고른다. 소닉 프레임은 가장 큰 것이 대략 45px이므로 배율 **8~12** 정도를 기준으로 조정한다. (배율 12면 높이 약 540px)
- **중복 없는 코드**: 그리기·재생 코드는 `play_animation` 한 곳에만 둔다.
- **읽기 쉬운 데이터**: 프레임 좌표는 한 줄에 몇 개씩 정리하고, 리스트마다 어떤 동작인지 주석을 단다.

## 7. 화면 설계

```
+-------------------- 1200 -------------------+
|                                             |
|                (동작 이름)                    |  ← 선택: 현재 동작 이름 표시
|                                             |
|                  [소닉]                      |  ← 제자리 동작: CENTER_X(600), SCALE배 확대
|   [소닉] ───────────────────────────→        |  ← 이동 동작: 가장자리에서 출발해 가로로 이동
|                                             |  (높이 800)
|  ───────────────── GROUND_Y ────────────────  |  ← 발이 닿는 기준선(실제로 그리지는 않음)
+---------------------------------------------+
```

## 8. 코드 구조

```python
from pico2d import *

# 1. 설정 상수
SCREEN_WIDTH, SCREEN_HEIGHT = 1200, 800
SCALE, CENTER_X, GROUND_Y, FRAME_DELAY, PLAY_TIME, PAUSE_TIME

# 2. 캔버스, 이미지 로드
open_canvas(SCREEN_WIDTH, SCREEN_HEIGHT)
sonic = load_image('sonic-sprite.png')

# 3. 동작별 프레임 좌표 (left, bottom, width, height)
idle_frames = [...]
walk_frames = [...]
...

# 4. 재생 순서: (프레임 리스트, 가로 이동 속도)
animations = [(idle_frames, 0), (walk_frames, WALK_SPEED), ...]

# 5. 재생 함수
def play_animation(frames, speed): ...  # 5초 재생(이동 포함) + 1초 정지

# 6. 메인 루프
running = True
while running:
    for frames, speed in animations:
        play_animation(frames, speed)

close_canvas()
```

## 10. 이동 동작 설계

| 동작 | 리스트 | 속도(px/초) | 이유 |
| ---- | ------ | ----------- | ---- |
| 대기 | `idle_frames` | 0 | 제자리 |
| 걷기 | `walk_frames` | `WALK_SPEED = 150` | 천천히 이동 |
| 달리기 | `run_frames` | `RUN_SPEED = 400` | 빠르게 이동 |
| 스핀 | `spin_frames` | 0 | 몸을 마는 동작 |
| 볼 | `ball_frames` | `ROLL_SPEED = 500` | 구르며 이동 |
| 가속 | `dash_frames` | `DASH_SPEED = 300` | 속도를 올리는 중 |
| 피겨에이트 달리기 | `peel_out_frames` | `PEEL_OUT_SPEED = 700` | 최고 속도 |
| 제자리 회전 | `turn_frames` | 0 | 제자리 |
| 피격 | `hurt_frames` | `HURT_SPEED = -200` | 뒤(왼쪽)로 밀려남 |
| 정면 달리기 | `front_run_frames` | 0 | 화면 쪽으로 달려서 가로 이동 없음 |
| 놀람 | `surprise_frames` | 0 | 제자리 |
| 포즈 | `pose_frames` | 0 | 제자리 |

- 출발 위치: 제자리는 `CENTER_X`, 오른쪽 이동은 `START_OFFSET`(200), 왼쪽 이동은 `SCREEN_WIDTH - START_OFFSET`. 완전히 화면 밖에서 출발하면 걷기 속도에서 약 2초 동안 안 보이므로 가장자리 안쪽에서 출발한다.
- 위치 계산: `x = 출발 x + speed × 경과 시간`
- 화면 감싸기: 양쪽에 `EDGE_MARGIN`(가장 넓은 프레임 480px의 절반보다 큰 300px)만큼 여유를 두고, `x = (x + EDGE_MARGIN) % (SCREEN_WIDTH + 2 * EDGE_MARGIN) - EDGE_MARGIN`으로 반대편으로 넘긴다.
